# 第 10 次课 · 我的作品，我来讲（学员文档）

_柴火创客学院 M0 · 零基础智能硬件入门_

## 一、这节课你会带走什么

**最后一课。**十次课，今天收官。

下课的时候，你会带着这些离开教室：

1. **你的作品成品**——经过"只修不加"的冲刺和发布检查，在陌生人面前一次就能演通；
2. **一份 README**——你作品的"自我介绍 + 成长史"，由十次课的日志合体而成；
3. **一页纸 pitch**——问题、方案、给谁用、值多少，四格，让别人 2 分钟听懂并心动；
4. **一次真路演**——你先演示（东西真的动），再讲；
5. **十次课，全部点亮。**

今天三幕：**第一幕 · 最后一棒**（修好、跑稳）→ **第二幕 · 把作品讲出去**（README、算账、pitch、陪练）→ **第三幕 · 路演与结课**（真人路演、互投、仪式）。

## 二、30 秒复习

- 马拉松三棒跑了两棒：第一版最小闭环 → 请外援（代码外援 + 外观外援），功能完成、样子也像样了；
- 上一棒留给你的**交接单**写着：评审挑出的毛病、还没打磨的地方；
- 你有十次课的日志、一份需求单、两个硬通货：真实用户、真实需求单（今天再加一个：真实成本）。

今天只剩一件事：**让你的作品，被听懂。**

## 三、今天的新词（用大白话）

**README**——你作品的"自我介绍 + 成长史"。别人不看作品、只看它，也能懂你的作品是什么、怎么来的。它由你十次课的日志整理而成——AI 整理，你校对。

**算一笔账**——给作品算两笔：**它花了多少**（物料成本）、**它值多少**（你定价 + 一句"凭什么"）。注意：今天只算这两笔——不谈利润，不聊生意。算成本是数学，说价值是表达。

**pitch（一页纸）**——让别人 2 分钟听懂并心动的那一页纸。四格：问题 / 方案 / 给谁用 / 值多少。

**投资人陪练**——让 AI 扮一个"不懂技术、会打断、只问'所以呢？跟我有什么关系？'的人。被它问倒不扣分——**在这里把恐惧用完，台上就不怕了。**

**发布检查**——最后一轮评审：不挑刺，只问"它能不能见人"。清单上必须有一项有答案：**"出错了怎么救？"**

## 四、第一幕 · 最后一棒（只修不加）

### 第 1 步：站会

读你的棒交接单，一句话：

> "我要修好______，让演示稳在______。"

⚠️ 纪律四个字：**只修不加。**想加的新功能？"以后再做"清单欢迎它。

### 第 2 步：冲刺 45 分钟

只做两件事：

1. 修掉评审遗留的毛病；
2. **打磨演示稳定性**——连续演示 5 遍全过，才算"稳"。路演时，它必须在陌生人面前一次走通。

外壳还没收尾的：第 9 课的四招，10 分钟能收就收；收不掉，就这样上场——**功能是必答题。**

### 第 3 步：发布检查

```text
基于当前状态：我的作品现在能___，还不能___。
你是发布检查员：它 1 小时后要面对一群陌生人演示。
给我一张"发布前最后检查"清单：演示前必须确认的每一项
（电够不够？线插紧吗？演示的第一步是什么？出错了怎么救？）
```

逐项打勾。**"出错了怎么救"必须有答案**——答不出就用备份：你日志里的演示照片/视频。

> 💡 **工程师的同款检查表**：Brandy（第 8 课附录那位 Seeed 工程师）做分享前就查四条：① 灯，立即亮吗？② 录音，正常结束吗？③ 识别的文字，完整吗？④ Prompt，进对窗口吗？前两条查"它真的在干活吗"，后两条查"活干得完整吗"——**换成你作品的对应动作，抄进你的清单**。她的降级方案：现场失败，串口日志、录屏、成品视频备着——你的"出错了怎么救"，就是这个。

改不完的真毛病？写进 README 的"还不完美的地方"——**缺陷坦白是加分项。**

## 五、第二幕 · 把作品讲出去

### 第 4 步：README（日志合体）

十次课，你写了十篇日志。今天它们合体。老规矩：AI 整理，你校对：

```text
这是我十次课的日志：（贴入全部日志）
请只依据这些日志，整理成一份 README，模板如下：
它叫什么 / 帮谁解决什么问题 / 怎么用（三步以内）/
它是怎么长大的（挑 3 个关键时刻）/ 还不完美的地方 / 以后还想加。
不要补充我没说过的内容。
```

生成后逐句校对：**有没有它编的？**抓到就删——AI 会一本正经地编，校对是你的事。十次课了，这是最后一次现场考试。

README 模板（AI 整理完，自己誊一遍骨架）：

```text
# 我的作品 README
## 它叫什么：
## 它帮谁解决什么问题（真人名字）：
## 怎么用（三步以内）：
## 它是怎么长大的（3 个关键时刻：立项 / 卡住 / 改好）：
## 还不完美的地方（诚实写 1–2 条）：
## 以后还想加（从"以后再做"清单里挑）：
```

### 第 5 步：算一笔账

看投屏的算账口径，两步：

```text
只算两笔：
一、它花了多少——物料清单（外壳材料也算，哪怕它是个外卖盒）
二、它值多少——我认为它值___，因为___
（贵的理由必须是"它解决了什么问题"，不是"我想要"）
```

1. 列你的**物料清单**——用了哪些元件、什么外壳材料，让 AI 帮你核对有没有漏；
2. **写一个数字 + 一句理由**。

⚠️ 定价可以比成本贵——但贵的理由必须是"它解决了什么问题"，不是"我想要"。说不圆？降价降到能说圆为止。

### 第 6 步：pitch 一页纸

四格，每格不超过两句。**三处硬引用，编不了**：

```text
# 我的一页纸 pitch

## 问题（谁遇到了什么麻烦——需求单上的原话）：

## 方案（我的作品怎么解决 + 演示动作）：

## 给谁用（第 2 课名单上的真人名字）：

## 值多少（引用刚才算的账：成本___，我认为值___，因为___）
```

### 第 7 步：AI 投资人陪练

```text
你现在是一个完全不懂技术的投资人。
我念一页 pitch 给你听，你随时可以打断我，
只许问两类问题："所以呢？"和"跟我有什么关系？"
如果我答得听不懂，就追问到听懂为止。
```

被问倒 → 改 pitch → 再念。它要是夸你，顶回去："不许夸，只许问'所以呢'。"

每个"答不上"都是礼物：**把它改成 pitch 里的一句话，台上就没人能问倒你。**

## 六、第三幕 · 路演与结课

### 第 8 步：真人路演

规则三条：

```text
路演三规则：
一、先演示，再讲——东西真的动，比什么都响
二、每人 2 分钟——沙漏不豁免任何人
三、桌内全员轮讲，每桌推 1 人全场
```

⚠️ 沙漏不豁免任何人——2 分钟说不完 = 还没想清楚，讲完这句收。

### 第 9 步：互投

```text
听众任务：3 票投给"最想让它真实存在"的作品——不许投自己
```

⚠️ 不敢上台？先在桌内讲；还不行，和同桌一起上（你演示他讲）。**底线是不缺席。**

### 第 10 步：结课仪式

互投之后，是十次课的最后 15 分钟：

- **十次课，全部点亮**——点亮第一盏灯 → 找到值得做的题目 → 作品有了屏幕 → 有了 AI 团队 → 教硬件学会看 → 搬回自己的电脑 → 立项 → 跑通第一圈 → 请来了外援 → **今天，把它讲了出去；**
- 还记得第 1 课吗？你点亮了第一块硬件，屏幕上是你的名字。今天，你的名字在你的作品上、在 README 里、在别人的掌声里——**你不再是看魔术的人，你是变魔术的人；**
- 最后一次日志 + 合影（老规矩：举作品、举手、背影，只拍手不拍脸）。

## 七、工作台 · 路演自检表（上台前打勾）

```text
□ 先演示再讲：我的演示第一步是什么，我背得出
□ 连续演示 5 遍全过
□ 2 分钟说得完（掐表练过一遍）
□ pitch 四格齐全，每格不超过两句
□ "给谁用"是真人，"值多少"引用了我的账
□ 被"所以呢"问过一轮，我接住了
□ 备份就位：作品坏了，我有照片/视频顶上
□ "出错了怎么救"我有答案
```

## 八、卡住了怎么办

| 我卡在这儿 | 怎么办 |
| --- | --- |
| 作品还有毛病 | 写进"还不完美的地方"。坦白是加分项。 |
| 作品临上场坏了 | 播备份视频/照片 + 现场讲——这叫"工程师的备份意识"。 |
| 日志不够做 README | 对着作品补两条"拍一张、说三十秒"，再生成。 |
| README 写得比我的经历还精彩 | 警惕：那是 AI 在编。逐句问"这条我日志里写过吗"。 |
| 定价不知道定多少 | 随便定——然后把"凭什么"说圆，说不圆就降价。 |
| 投资人把我问倒了 | 太好了。把答不上的改成 pitch 里的一句话。 |
| 我不敢上台 | 桌内先讲 → 同桌双人上 → 底线是不缺席。 |
| 2 分钟讲不完 | 砍"方案"细节，保"问题"和"演示"。说不清的不是重点。 |

## 九、今天的 AI 日志（最后一次）

老规矩，四句：

```text
今天做了：
卡在：
后来：
下次想：
```

今天"做了"那句写：**十次课，我做过最骄傲的一件事是___。**

翻一翻你的十篇日志——从"第一次点亮"到"我的作品我来讲"。这十篇，就是你长成本事的全过程。**别人只有一个作品，你有作品 + 它的成长史。**

## 十、这套本事跟你走

十次课点亮的不只是硬件：

- **会感知、会应答**——硬件能听你的话了；
- **会找题**——从自己的体验里长出值得做的题目；
- **会带团队**——五个 AI 角色，你是指挥；
- **会交付**——最小闭环 → 请外援 → 只修不加，三棒跑完一个马拉松；
- **会讲出去**——README、算账、pitch、路演，让别人听懂并想要。

**做一个东西，讲清楚它，让别人也想要——这套本事，学校不教，但你已经会了。**
