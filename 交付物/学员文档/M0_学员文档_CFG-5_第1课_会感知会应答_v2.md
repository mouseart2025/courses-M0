# 第 1 次课 · 会感知，会应答（学员文档）

_Grove Beginner Kit · 物联网入门开发板 ｜ 柴火创客学院 M0 · 零基础智能硬件入门_

---

## 一、这节课你会带走什么

今天是你第一次让硬件听你的话。下课的时候，你会有四样东西：

1. **一块写着你名字的板子**——你的名字出现在屏幕上，你亲手点亮的；
2. **三个会"感知→反应"的小作品**——一个跟着老师做的，两个你自己选的；
3. **你的第一条 AI 学习日志**——拍一张、说三十秒，30 秒就能搞定；
4. **认识这门课要练的六种本事**——会出题、会找用户、会做出来、会取舍、会判断好坏、会讲给别人听。今天先练两样：做出来，和讲清楚你是怎么做的。

先说清楚一件事：**今天所有的代码都是 AI 写的，一行都不用你写。**

你的活只有三件：说清楚、看效果、继续改。

## 二、三分钟认识你的板子

你桌上这块板子叫 Grove Beginner Kit——它有个正式名字叫**开发板**，你可以把它当成一台迷你电脑。它比你的手机笨得多，但有一个手机比不了的本事：你给它一件事，它能一直做，做一年也不烦。它把一堆小零件装在了一起，不用焊接，插上 USB 线就能用。

用大白话认识一下它：

- 🧠 **中间那块**——它的脑子。你说的话（通过 AI）最后都变成它要干的事。
- 📺 **屏幕（OLED）**——它的脸。可以显示文字和数字。
- 💡 **LED 灯**——它会发光，最简单的一种"表达"。
- 🔊 **蜂鸣器**——它的嗓子，会"哔哔"叫。
- 🌗 **光线传感器**——它的眼睛之一，能感觉到周围亮还是暗。
- 🎤 **声音传感器**——它的耳朵，能听到声音大不大。
- 🌡️ **温湿度传感器**——能感觉到冷热和干湿。
- 🏃 **加速度计**——能感觉到板子有没有被碰、被晃。
- 🎈 **气压传感器**——能感觉到空气压力的细微变化。气压跟着海拔和天气变，所以它既能"知道"你拿着板子爬了几层楼，也能感觉到天要变。
- 🔘 **按钮和旋钮**——让你动手操作它的地方。

记住这个感觉就行：**板子上半部分负责"感觉"，下半部分负责"表达"，中间的脑子负责"决定"。**决定怎么做的人——是你。

今天先记住一句规矩：板子上的小模块以后可以掰下来单独用，但今天先不掰，老师说掰再掰。

## 三、跟 AI 合作三步法

今天你所有作品都按同一个节奏做出来：

```
说清楚 → 看效果 → 继续改
```

老师课上会带你们念两句**咒语**，就印在这页上，忘了就翻。

**第 1 步：说清楚。**
打开 Codecraft——它是一个网站，就是你跟 AI 说话、AI 帮板子写指令的地方。在输入框里用一句中文告诉 AI 你要什么（这句话有个名字，叫**提示词**）。

> **咒语 1：一次只说一件事。**

照着这个句式说，最稳：

```
我用的是 Grove Beginner Kit。请帮我做一件事：＿＿＿（只写一件）。做到 ＿＿＿ 就算成功。请先不要加别的功能。
```

**第 2 步：看效果。**
AI 会把你的话变成板子看得懂的指令——屏幕上会跑过三个词：**生成**＝AI 在写指令；**编译**＝它把指令翻译成板子听得懂的话；**烧录**＝把翻译好的指令顺着 USB 线搬进板子（搬进去就记住了，拔线也忘不掉）。然后你看：板子做的事，是你要的吗？

**第 3 步：继续改。**

> **咒语 2：不对，就往下补一句。**

别删对话、别重开，就在原来的对话里**往下补一句**。AI 记得你们前面聊的。

### 提示词写法小技巧

- 说清两件事：**什么时候**（条件）＋ **做什么**（动作）。
  - 不清楚 ❌：「帮我做个灯」
  - 清楚 ✅：「光线变暗的时候，把 LED 灯打开」
- 一次只说一件事。想要三个效果，就说三次，一次一个。
- 效果不好就追问。太灵敏说"再迟钝一点"，不灵敏说"再灵敏一点"。
- AI 是在**猜**你的意思——你说得越清楚，它猜得越准。它也会猜错，所以第 2 步"看效果"永远是你的事。

## 四、任务一：点亮你的名字

**目标**：让屏幕显示出你的名字。

**提示词**（把名字换成你自己的，发给 AI）：

```
在屏幕上用大字显示：Hello, I'm ＿＿＿。
```

名字用拼音或英文——有些板子显示中文不稳，先用英文点亮最保险。想试中文名也行，显示不出来就换回英文，不丢人，回头我们再教它。

**做完之后**：等 AI 生成代码 → 编译 → 烧录。举起你的板子看。

✅ **屏幕出现你的名字，才算点亮。** 点亮了就举手，老师会给你桌上立一面小旗。

**想再玩一下？** 给它加一个你想要的效果——名字一闪一闪、加一声提示音、加个表情、让名字滚起来。一次加一个，比如：

```
让名字每秒闪一次。
```

```
让名字从右往左滚动显示。
```

```
显示名字的时候，让蜂鸣器响一声。
```

效果不好？往下补一句，比如：

```
不对，我想要它闪得更快一点。
```

## 五、三格图小课：感知 → 逻辑 → 输出

整学期做硬件，就一张图：

```
感知 → 逻辑 → 输出
```

- **感知**：它感觉到了什么（眼睛、耳朵）
- **逻辑**：它怎么判断（这是你的地盘，你说了算）
- **输出**：它做了什么（灯亮、叫、显示）

看三个例子：

| 东西 | 感知 | 逻辑 | 输出 |
| --- | --- | --- | --- |
| 自动门 | 看到有人来 | 判断要不要开门 | 门打开 |
| 空调 | 测量温度 | 比较温度高不高 | 制冷或停 |
| 妈妈 | 看到你在玩手机 | 判断该不该管 | 喊你 |

轮到你了——随便想一个你身边会"感知→反应"的东西，填一填：

| 我的例子：＿＿＿＿ | 感知：＿＿＿＿ | 逻辑：＿＿＿＿ | 输出：＿＿＿＿ |
| --- | --- | --- | --- |

今天后面两个任务，都要求你说得出自己的三格。**先说清楚三格，再动手做**——想清楚、说清楚，才做得出来。

## 六、任务二：天黑亮灯

**目标**：做一个天黑自己亮的小夜灯。

先对同桌说出三格：感知 = 光线，逻辑 = 暗了就开，输出 = LED 灯。

**提示词**：

```
当光线变暗时，打开 LED 灯；变亮时，关闭。
```

**玩一玩**：烧录完成后，用手捂住板子上的光线传感器——灯亮了吗？松开手——灯灭了吗？

**调一调**：教室里的光线和家里不一样，你的灯可能太灵敏或太迟钝。不用换任何东西，跟 AI 说：

```
现在太容易亮了，再迟钝一点。
```

```
现在不够灵敏，再灵敏一点。
```

调到你满意为止。真实世界里的传感器都要这样"调脾气"，这是正常操作，不是坏了。

## 七、任务三：自选传感器组合

**目标**：从板子上任选一个"感知"、一个"输出"，自己组合一个作品。

**硬规矩**：先跟同桌说出你的三格，再动手。说不出来，不许碰键盘。

**没灵感？三个备选：**

1. **拍手开灯**——拍一下手，LED 亮；再拍一下，灭。
   ```
   用声音传感器检测拍手：拍一下手，LED 亮；再拍一下手，LED 灭。
   ```

2. **迷你报警器**——一晃板子就叫，只有你知道怎么解除。
   ```
   用加速度计检测板子被晃动：一晃就让蜂鸣器报警、LED 闪烁，按住按钮 2 秒解除报警。
   ```

3. **桌面气象站**——屏幕上实时显示温度和湿度，太热就提醒你。
   ```
   在屏幕上实时显示温度和湿度，温度太高时让蜂鸣器短响一声提醒。
   ```

**🚩 挑战一下（给做得快的你）**：用**两个**传感器一起判断——比如"又暗、又有声音的时候才亮灯"，或者"边晃动边大声才叫"。自己把三格想明白，再跟 AI 说。还想玩更大的？找老师要挑战题——做个小游戏机（打地鼠、反应力计分），或者把板子变成游戏手柄，用按钮和旋钮控制电脑屏幕上的游戏。

## 八、报错怎么办

做的东西多了，你早晚会看到一大段红字。先记住：

> **报错不是坏了，是 AI 在跟你说话。**

看到红字，这样做：

1. 把报错**整段复制**下来；
2. 贴回给 AI，前面加一句"我刚才做了什么"；
3. 让 AI 告诉你原因和第一步怎么办。

**示范对话**：

```
我刚才让 LED 改成闪烁，然后编译报错了。
报错全文贴在下面：
【把红字原样粘贴在这里】
请告诉我最可能的原因，和第一步该做什么。
```

大多数时候，AI 看完自己的报错就能修好。你要学的不是"永远不出错"，而是**出错后把问题准确地交给 AI**。

## 九、我的第一条 AI 日志

从今天起，每次课结束前都做一个 30 秒的小仪式：**拍一张、说三十秒。**

**第 1 步：拍一张。**
拍你今天的作品。做砸的现场也值得拍——这些照片以后是你"成长史"里最珍贵的那张。

**第 2 步：说三十秒。**
对着手机（或对着 AI 打字），说完这四句：

```
今天我做了____；
卡在____；
后来____；
下次我想____。
```

"卡在哪"必须说。今天没卡？那就说："太顺了，我反而担心____。"

**第 3 步：让 AI 整理，你来校对。**
把你说的发给 AI：

```
帮我整理成一条学习日志，格式：日期／做了／卡在／下次。
只整理我说过的，不许加我没说的。
```

它整理完，**你必须看一眼再确认**。AI 会一本正经地编——把没说过的说得跟真的一样。校对是你的事，谁也替不了。

为什么费劲记这个？别人结课只有一个作品，你结课有一个作品**加它的成长史**。比赛、面试、汇报——成长史比作品值钱。

## 十、收好这三句话，后面用得上

今天不用急着全记住，先混个脸熟——后面几节课会一个一个用到：

- **「这段代码在干嘛」**——想知道 AI 写了什么，让它用大白话解释；
- **「把日志变成 README」**——攒下的日志，结课时变成作品的项目介绍；
- **「讲给没看过的人听」**——把作品介绍翻译成完全不懂的人也能懂的话。

做什么、做得对不对，永远你说了算——这些话术只是帮你把话说清楚。

## 十一、下次课预告 + 一个小思考

下次课，我们要干一件更重要的事：**找到那个值得你一直做下去的题目。**好作品都是从好问题长出来的。

**留一个小思考，不用写，路上想想就行：**

> 你身边，有什么小事让你烦？
> 家里、学校里、路上——有什么天天要人跑腿、天天要人盯着的事？
