# 第 3 次课 · 给作品装上屏幕（学员文档）

_柴火创客学院 M0 · 零基础智能硬件入门_

## 一、这节课你会带走什么

上节课你找到了自己的题目。今天发新装备——你的作品从今天起有**真正的界面**了。

下课的时候，你会有四样东西：

1. **一张"我的 Wio 认识单"**——新板子导览一圈＋ 5 个"点亮它"微实验，你亲手点亮了几样，就在这份文档里打几个勾；
2. **两句新句式**——一句让板子干活的指令开头，一句把界面说清楚的老司机句式，全文都在这份文档里；
3. **一个带屏交互作品**——按键计数器跟做＋一个两屏切换的界面作品，外加一句你说界面的得意描述；
4. **一条 AI 日志**——还是那四句，但今天的"卡在"要写具体：差的是位置、大小还是颜色。

今天重点练的本事还是**会做出来**——只不过这次，做出来的东西有脸、有手。

先说清楚这节课的玩法：**老师引导＋这份文档＋AI 对话 → 你自己的作品和记录。**每一步老师让你写的东西，都写在这份文档上（用电脑的就记在 md 文档里，手写的就写在纸上）——下课要交，后面几节课都要用。

## 三、新装备：Wio Terminal，一台掌上小电脑

它叫 **Wio Terminal**——你可以把它理解成一台掌上小电脑：

- **彩色大屏**——作品的脸：界面、数字、图形都在这；
- **三颗按键＋一个五向摇杆**——人的手：按一按、拨一拨，给作品下命令；
- **自带传感器**——它自己带耳朵和身体。

### 一个和旧板子不一样的地方：烧录开关

烧录之前，侧面的开关**滑一下、再滑一下**——这是告诉板子"准备接收新指令"。

口诀就一句，贴在桌上：**没反应？滑一下。**

### 热身：老流程，一句老话

换板型重连 Codecraft——选 Wio Terminal，老流程。然后发一句你第一次课就会的话（把空填成你自己的名字，拼音或英文）：

```
我用的 Wio Terminal，请帮我实现下面功能：在屏幕上用大字显示 HELLO 和我的名字（拼音或英文）：＿＿＿
```

等你的屏幕亮起来——**换了新硬件，你会的东西一样不少，全都能用，而且字更漂亮了。**

（为什么显示用英文？这块板的中文字库不稳，这节课所有屏幕显示一律用英文、数字或图形。）

### 转一圈，认识你的新伙伴

跟着老师，每报一个名字，用手指在板子上找到它、摸一下：

| 部件 | 一句话 |
| --- | --- |
| 彩色大屏 | 作品的脸：界面、数字、图形都在这 |
| 三颗按键 | 人的手：按一按，下命令 |
| 五向摇杆 | 人的手：游戏机、菜单靠它 |
| 麦克风 | 听得到动静 |
| 光线传感器 | 知道亮暗 |
| 加速度计 | 知道动没动、往哪边歪 |
| 蜂鸣器 | 会出声：提醒、报警 |
| SD 卡槽 | 能存东西——先知道存在 |
| Grove 接口 | 以后加新模块的门——先知道存在 |

最后两个今天只用耳朵听。它能联网？也能——那是后面的课，今天先记住它存在。

## 四、点亮它：五个微实验

光摸不算认识——**点亮它才算**。五个微实验，每个你就发一句话，看它活过来。节奏：老师先发一遍，你们再发——别光看老师，你发一句试试。

发指令统一用这个开头（全文就在这，照抄就行）：

```
我用的 Wio Terminal，请帮我实现下面功能：……
```

### 微实验 1 ｜ 三键琴（按键）

```
我用的 Wio Terminal，请帮我实现下面功能：按 A/B/C 键分别发出 do、mi、sol 的音，屏幕大显示 DO / MI / SOL
```

按一按，它会应你——A、B、C 三颗键，就是一台小琴。能弹出一小段，就举手。

### 微实验 2 ｜ 推着小球跑（摇杆）

```
我用的 Wio Terminal，请帮我实现下面功能：屏幕中间画一个小球，摇杆推向哪边，小球就往哪边移动
```

摇一摇，小球听你的——看谁能把球稳稳推到角落里。**彩蛋：摇杆按下也能按**，发现的举手。

### 微实验 3 ｜ 吹蜡烛（麦克风）

```
我用的 Wio Terminal，请帮我实现下面功能：屏幕中间画一支点燃的蜡烛，对麦克风吹气火焰熄灭，过 2 秒重新点亮
```

吹口气，蜡烛就灭——声音不用报数，能办事就行。

### 微实验 4 ｜ 怕黑的板子（光线）

```
我用的 Wio Terminal，请帮我实现下面功能：屏幕画两只睁开的眼睛；光线变暗时眼睛闭上并显示 ZZZ，变亮时重新睁开
```

盖住它，它就睡着了——上节课"天黑亮灯"的本事，换了个玩法。

### 微实验 5 ｜ 平衡球（加速度计）

```
我用的 Wio Terminal，请帮我实现下面功能：屏幕画一个方框，框里一个小球，倾斜板子小球往低处滚动
```

歪一歪，小球往低处滚——摇晃检测、摔倒报警，都靠它。

**节奏提醒**：一句指令只点亮一个硬件点（老规矩：一次一件事）；某句跑不通，举手找老师换一句，别死磕。做得快的，给当前的玩具自由加一句（"给小球换个颜色""球碰到边就响一声"）；跟不上的，保住前三个就算达标。

**写在这里：我点亮了（打一个勾算一个）＋一句惊喜**

- □ 按键　□ 摇杆　□ 麦克风　□ 光线　□ 加速度计

> 最让我惊喜的是＿＿＿＿＿＿，因为＿＿＿＿＿＿＿＿＿＿＿＿。

## 五、界面这样说才清楚：对比实验

硬件都点亮了，现在学用好它的第一课：**怎么让 AI 给你一个好界面。**

课上老师做了个小实验，同一句话两种说法：

- 说法一：只说"做个计数器界面"——AI 自由发挥；
- 说法二：把样子说清楚——"屏幕中间用最大号字显示数字，左上角小字显示 COUNTER，数字是红色"。

差别在哪？**说界面，要说清楚三样东西：位置、大小、颜色。**

界面句式全文在这，忘了就翻：

```
在【位置】用【大小/颜色】显示【内容】，当【操作】时【变化】。
```

例子：在屏幕正中间用最大号红色字显示数字，当按 A 键时数字加一。

再补一句，和上节课区分开：**说逻辑**，是"什么条件干什么"；**说界面**，是"什么东西在什么位置长什么样"。两种表达，都要会。

## 六、跟做：按键计数器（分两步说——这是故意的）

**步骤一 · 只说界面：**

```
屏幕中间用最大号字显示数字 0，左上角小字写 COUNTER。
```

烧录，看效果。

**步骤二 · 再说行为：**

```
按 A 键数字加一，按 B 键清零。每按满 10 下，蜂鸣器响一声庆祝。
```

再烧录。按满 10 下，听它给你鼓个掌。

**先说样子，再说动作——两种表达，分两次说，它就不乱。**不对？别推倒重来，往下补一句，它就会了。按键没反应？想起桌上那句口诀——**没反应？滑一下。**

## 七、自由创作：做一个有两个画面的东西

命题一句：

```
做一个有两个画面的东西，用按键或摇杆切换。
```

候选题目：时钟 ／ 心情显示器 ／ 秒表 ／ 自制菜单 ／ 反应力测试（屏幕变绿就按 A，显示你的毫秒数——天生就是两个画面）。显示内容用英文、数字或图形。

你手里现在有五种输入——按键、摇杆、麦克风、光线、加速度计——挑顺手的用，刚才点亮的玩具都能直接搬进作品。

**老纪律**：先对同桌**口头描述**两个画面各长什么样——位置、大小、颜色说清楚——再跟 AI 说。说不清的那句，就是你待会儿要补的那句。

三个提醒：

- **导演一场一场拍**——先把第一个画面说漂亮，再说第二个，最后才说怎么切，别一句让 AI 全干；
- 按键没反应、界面字溢出、颜色不显——都是"补一句描述"就能解决的事；
- 实在做不出两个画面：达标线降为"计数器＋一处你自己的修改"，把卡在哪写进日志，照样算完成。

**今天的达标线（人人必须过）**：计数器跑通＋一个两屏界面作品。

**写在这里：我跟 AI 说界面的那句话**（抄一句你最得意的描述）：

```
＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿
```

## 八、跑偏展览：翻车不是笑话，是教材

课上全班围观了一个"宝贝"：一个说歪了、AI 做跑偏的界面。

- 他说的是：＿＿＿　→　AI 做的是：＿＿＿　→　差在哪一句？

找到差的那一句，比做出一个漂亮界面更值钱——**翻车不是笑话，是教材。**感谢替全班踩坑的同学，他是功臣。

如果那个跑偏的界面是你的：不用不好意思，你已经帮全班（包括老师）交了一次学费。

## 九、收束：三条要领＋今天的日志

用好这台掌机的三条要领：

1. **界面要说清位置、大小、颜色**——说不说这三样，出来是两个东西；
2. **状态要看得见**——让屏幕显示"现在走到哪一步"，你才知道它在干嘛；
3. **输入多，就多试几种组合**——好作品常常是"哪个输入最顺手"试出来的。

**写在这里：圈一句**

> 今天我最常用到的是第＿条。

**今天的日志，四句不变**——今天的"卡在"写具体：差的是位置、大小还是颜色。

第 1 步：**拍一张**你的界面作品（只拍手和板子）。

第 2 步：**说三十秒，四句说全**：

```
做了＿＿＿＿；
卡在＿＿＿＿（写具体：差的是位置、大小还是颜色）；
后来＿＿＿＿；
下次想＿＿＿＿。
```

第 3 步：**让 AI 整理，你来校对。**说完发给 AI：

```
帮我整理成日志，只许整理我说过的，不许加我没说的。
```

它整理完，**你必须看一眼再确认**——AI 会一本正经地编，校对是你的事，谁也替不了。

**写在这里：今天的日志（校对后的版本）**

＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

## 十、缓冲时间：先达标，再放飞

课堂最后有一段机动时间，听老师宣布今天主打哪个出口：

1. **补达标（人人必须过线）**：还没做出"计数器＋两屏作品"的，继续做完；
2. **进阶挑战（过了线的领）**：
   - **电子骰子**——晃一晃（或摇一下摇杆），屏幕随机出 1–6；
   - **平衡球进洞**——给微实验 5 的平衡球加一个目标洞，球进洞，蜂鸣器响一声；
3. **帮同桌＋加联动**：帮同桌过线（只能动嘴，不能碰他的键盘）；或给你的两屏作品加一个传感器联动——比如光线暗了，自动切到夜间界面。

铁律一句：**先保人人达标，再放飞快手。**

**写在这里（做了挑战的同学写）：**

> 我用＿＿＿＿（哪种输入）做了＿＿＿＿＿＿＿＿（什么小东西）。
