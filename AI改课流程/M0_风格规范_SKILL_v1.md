# M0 课程风格规范（风格 Skill）

> 柴火创客学院 M0 · 零基础智能硬件入门 ｜ 适用仓库：github.com/mouseart2025/courses-M0
> 本 Skill 是 AI 产出任何四件套前的**风格基准**。内容基准见《M0 课程设计 Skill》。

---

## 一、总纲：这门课"长什么样"

一条主轴：**它是一套"给人照着用、也欢迎被改"的课程，不是论文，不是广告，不是说明书。**

三条风格红线（任何产出不得违反）：

1. **人话优先**：所有面向老师/学员的文字，先像人说的话，再像规范文档。术语出现时必须伴随一句大白话解释。
2. **口语化但不失准**：话术可以口语、可以幽默，但技术事实必须正确（"陆志荣测试"：口语化不得牺牲技术正确性）。
3. **零打印、零花哨**：一切展示材料投屏即可；不设计需要老师打印/自制的物料；不出现拍立得、实体卡片之类管理道具。

---

## 二、文档总风格（三类共用）

### 2.1 语言

- 简体中文（英文版参照 `en/` 本地化方法论：本地化 ≠ 直译）。
- 第二人称称呼读者：对老师是"你"，对学生也是"你"。
- 避免书面腔：能说"看"不说"查看"；能说"做"不说"执行"；能说"卡住"不说"遇到阻塞"。
- 数字与时长：不写死具体钟点，只给时长与相对节点（"下课前 15 分钟必进仪式"）；新增数字要给出处或标注估算。

### 2.2 结构与命名

| 产物 | 文件名（对外课名去标点） | 版本 |
| --- | --- | --- |
| 教师讲义（讲师版） | `M0_教师课件_CFG-x_第N课_课名_vX.md` | 从 v1 起，改版升号 |
| 教师 PPT 策划 | `M0_PPT策划_CFG-x_第N课_课名_vX.md` | 与 PPT 同版本 |
| 教师 PPT | `M0_演示文稿_CFG-x_第N课_课名_vX.pptx` | 与策划同版本 |
| 学生文档 | `M0_学员文档_CFG-x_第N课_课名_vX.md` | 从 v1 起 |
| 课程大纲 | `M0_课程大纲_[配置名]_v1.md` | 从 v1 起 |

- 课名用**对外展示课名**，过「一眼懂」测试：不看背景材料的人，只看标题能说出这节课大概做什么。反面教材：《让它活起来》（自嗨式比喻）。
- 内部编号（积木编号 X0/A1…、内部课名）只出现在文档页脚，不在正文和对外标题出现。

### 2.3 文档头与页脚

- 文档头：一句课程定位（`柴火创客学院 M0 · 零基础智能硬件入门 ｜ CFG-x ｜ 第 N 课`）。
- 页脚：版本号 + 修订说明（改版必须写一行"改了什么、为什么"）。

## 三、教师讲义（讲师版）风格

**性质**：内容权威、单文档自包含——老师只读这一份就能上课。

### 3.1 固定结构（顺序不可乱）

```
第一页：开课前只看这一页
  这节课讲什么（学员产出三样东西，逐条列）
  你需要会的三件事 / 你不需要会的三件事
  出状况怎么办（三板斧：换不修、切备份、问 AI）
一、课前准备（开课前一周 / 当天 / 演示预演步骤 / 物料三分类）
二、课程总览表（环节 | 学员在做什么 | 你要做什么 | 时长）
  2.1 时间松紧带（可压/不可压）
  2.2 助教分工速查（有助教就照这个分）
三、分段逐字流程（每段：目标 → 🗣️ 念 → 👀 看 → ⚠️ 应对）
四、演示双保险一览（预演 | 备份素材 | 现场不顺时）
五、翻车应对速查表 + 学员常问问题怎么接
六、本课提示词句式库（讲师参考，投屏展示）
七、本地化替换位清单（默认内容 → 可替换为）
八、讲师反馈页（课后 10 分钟填写）
```

### 3.2 三色话术标记

| 标记 | 含义 | 用法 |
| --- | --- | --- |
| 🗣️ 念 | 逐字话术 | 老师照着念的口语，一字不差写好，不许让老师临场编 |
| 👀 看 | 巡场观察点 | 老师该看什么、注意什么、怎么巡场 |
| ⚠️ 应对 | 翻车预案 | 出状况时的具体动作与话术 |

### 3.3 口吻要求（G1–G8 核心）

- **"你不需要会"前置**：先告诉老师哪些不需要会（写代码/修设备/答技术问题），再讲要做什么——降低老师的上场焦虑。
- **设计层零出现**：积木编号、配置代号等内部词只放页脚；正文只有老师看得懂的话。
- **本地化替换位**：讲师自我介绍、生活例子、案例人物都要留"默认 → 可替换为"表格。
- **双保险**：每个现场演示都有备份方案（录屏/备用机/已跑通工程），且写明"这不算事故"。

### 3.4 时长纪律

- 用钟面时刻作总览表参考（14:00–14:30），但全文按相对节点写（"下课前 15 分钟"）。
- 每课标出：不能砍的三段（魔法演示/底线产出/课末日志）、可以压缩的、可以提前结束的。
- 预估时间要符合实际：AI 任务几分钟出结果，就不要排几十分钟。

## 四、学生文档风格

**性质**：学生视角，自己能看懂、能照做、卡住有自救指引。

### 4.1 体例（v2 确立，后续课照此）

- 第二人称"你"；操作引导 + 填空记录区一体，每个环节设「写在这里」的**成果锚点**（含＿＿空位）。
- 本课用到的 AI 句式**全文可复制**（含＿＿空位，空必须由学员自己填，空着发不出去）。
- 与教师讲义口径一致：同一句式、同一课名、同一时长算法；**不把讲师话术原文搬进来**。
- 全文无 emoji（v2 体例；旧版 emoji 风格已弃用）。
- 标题过「一眼懂」测试，不用内部编号称呼。
- 内嵌对应提示卡（提示卡库见 `课程策划与规划/M0_AI协作提示卡库_骨架_v1.md`）。

### 4.2 学员文档 vs 教师讲义的分工

| 视角 | 教师讲义 | 学生文档 |
| --- | --- | --- |
| 面向谁 | 老师 | 学生 |
| 内容 | 流程、话术、时长、预案 | 任务、提示词、句式、填写区 |
| 口吻 | "你带学员…" | "你来做…" |

## 五、教师 PPT 风格（柴火品牌规范）

**性质**：投屏成品；页面级设计由《PPT 策划》先行，PPT 逐页忠实执行。

### 5.1 配色（严格遵循，不可自行改色）

| 颜色 | 色值 | 占比 | 用途 |
| --- | --- | --- | --- |
| 白色 | `#FFFFFF` | 70% | 背景、留白 |
| 黄色 | `#F3D230` | 15% | 强调、图标、连接线、章节竖条 |
| 黑色 | `#000000` | 10% | 全部文字、线条、描边 |
| 红色 | `#D84144` | 5% | 关键数据、警示、核心亮点、禁止项 |

唯一例外：代码框浅灰底 `#F5F5F5`。**全 deck 禁止第五种颜色、禁止渐变、禁止阴影。**

### 5.2 字体与尺寸

- 字体：思源黑体（缺失时 PingFang SC / Noto Sans CJK SC，全 deck 统一）。
- 字号：幻灯片标题 36–40pt Bold / 章节标题 28–32pt Bold / 正文 18–22pt / 说明 14–16pt / 脚注 10–12pt。
- 尺寸：16:9（960×540px）；标题区顶部 100px；内容区 110–490px；脚注区底部 40px。
- 图标：2px 黑色描边线性图标；找不到合适图标用黄色圆点/编号替代。

### 5.3 信息密度

- 每页核心信息 ≤3 点；实操步骤**一步一页大字**；演示步骤页配合讲师操作、内容精简；互动页大字 + 问题引导。
- 学员动手时段，投屏页面保持不动——屏幕是学员的操作参照，不是讲师的提词器。
- 教师侧信息（铁律/巡场节奏/时间弹性带）只放备注页，**永远不上屏**。

### 5.4 常见页型（速查）

| 页型 | 版式 |
| --- | --- |
| 封面/章节封面 | 白底居中大标题（黑），标题下方黄色横线装饰 |
| 对比页 | 白底黑描边卡片，中间黄色箭头连接 |
| 流程页 | 白底黑描边卡片 + 黄色箭头串联 |
| 关键数据 | 数字用红色 `#D84144` 突出 |
| 强调框 | 黄色浅底或黄色左边框 |
| 编号列表 | 黄色圆点序号 + 黑色文字 |
| 互动页 | 大字体问题居中，充足留白 |

### 5.5 PPT 策划文档风格

- 每页必含：页面类型、停留时间、设计说明、展示内容、讲师讲稿（🗣️ 口径与教师讲义一致）。
- 文末附「用户确认点清单」，**对外课名候选列在第一位**。
- 策划是 PPT 的信源：PPT 生成后若用户手改定版，策划只做对齐回写，不再反向改成品。

## 六、全课通用口径（任何改造不得破坏）

1. **零打印**：所有提示语/句式都在 PPT 投屏或学生文档里，不打印物料；
2. **无统一休息**：学生按自己节奏，不设统一休息；
3. **不写死时刻**：只给时长与相对节点，按实际上课时间推算；
4. **老师只巡不教**：学生看文档、和 AI 沟通完成任务；
5. **合影纪律**：只拍手、不拍脸（举作品/举手/背影），影像公开需家长授权。

## 七、风格自查清单（产出前逐项过）

- [ ] 三色话术标记齐全，🗣️ 话术可以"照着念"不卡壳
- [ ] 术语首次出现都有大白话解释；口语化没有牺牲技术正确性
- [ ] 文件名、版本号、文档头页脚符合第二章规范
- [ ] 设计层内部词（积木编号/CFG）只出现在页脚
- [ ] 学生文档无 emoji、句式全文可复制、有成果锚点
- [ ] PPT 只有白/黄/黑/红（+代码灰），无渐变无阴影，每页 ≤3 点
- [ ] 本地化替换位、讲师反馈页保留（下一轮改造的接口）
- [ ] 全课通用口径五条未被破坏
