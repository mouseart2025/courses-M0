# AI 改课流程（目录）

_用 AI 把 courses-M0 改造成"你的课"的三份配套文档 ｜ 柴火创客学院 M0 ｜ v1 · 2026-09-08_

> **一句话**：courses-M0 是一套"拿来就能上、改了就更好"的开源课程。本目录教你（和你的 AI）怎么从需求出发，一步步把它改造成适合你教学环境的课。

---

## 本目录有什么

| 文档 | 是什么 | 什么时候读 |
| --- | --- | --- |
| **`AI改课流程指南_v1.md`** | 主流程：**说明需求 → AI 出大纲 → 大纲修订 → 逐课输出四件套（教师讲义 → PPT 策划 → PPT → 学生文档）→ 验收回传**，每一步带可复制的提示词模板与评审点 | 开始改课就从头读这份 |
| **`M0_课程设计_SKILL_v1.md`** | 课程设计 Skill：积木池、配置矩阵（CFG-0～CFG-5）、项目全流程八环节、四条硬规则、教学法脊柱——AI 出大纲时的"设计基准" | 第 2 步让 AI 出大纲、第 3 步修订时 |
| **`M0_风格规范_SKILL_v1.md`** | 风格 Skill：教师讲义/学生文档/PPT 三类的语言、结构、柴火品牌配色与命名——AI 产出任何课件时的"风格基准" | 第 4 步逐课产出四件套时 |

> 两份 SKILL 文档采用 SKILL.md 格式：可放入你的 AI 工具的 skills 目录使用，也可直接作为上下文文件粘贴给 AI。

---

## 三份文档怎么配合（30 秒版）

```
你（人）                         AI（机器）
─────────────                   ─────────────
1. 填《需求说明书》     ──────→   2. 读《课程设计 Skill》+ 需求 → 出大纲
   （流程指南 第二章）               （流程指南 第三章）
3. 评审/提修改意见      ←──────   4. 输出"原→改→理由"对照表 → 定稿大纲
   （流程指南 第四章）
5. 逐课确认            ──────→   6. 按《风格规范 Skill》逐课生产四件套
   （流程指南 第五章）               ①教师讲义→②PPT策划→③PPT→④学生文档
7. 验收（冷读/零基础/一致性）──→  8. 修订升版、附"改了哪些没改哪些"
   （流程指南 第六章）
```

## 与本仓库其他文档的关系

- **《交付物使用指南（给老师与 AI）》**（`交付物/` 下）：解决"怎么用、怎么小步改造单课"；本目录解决"从需求出发重设计整门课"。两者共用同一套教学法脊柱与全课通用口径。
- **内部生产流水线**（`.agents/skills/m0-course-authoring/`）：本目录是它对外公开的流程化版本；四件套顺序与命名规范完全一致。
