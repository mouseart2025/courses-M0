## 与中文版的关系

- **目录独立**：中文版在 `交付物/`，英文版在 `en/`，互不覆盖、互不混放；
- **信源单向**：英文版以中文版讲师版（已定版）为信源做本地化；英文版文档头标注 `Source: CN vX` 追溯；
- **版本解耦**：英文版独立版本号（从 v1 起）；
- **同步纪律**：中文版口径更新 → 英文版受影响段落标注 `[Sync: CN vX → EN]` 待同步。
